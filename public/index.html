FAF login not ready yet?

Until FAF registers our redirect URI, you can paste a short-lived access token from the FAF client. The token is kept only in this browser session on this server, cleared on logout or server restart, and is used only to call the official FAF API.

Where to find it in the Java client:
  1. Open the FAF Java client.
  2. Click your username in the top-right corner.
  3. Choose Copy access token.
  4. Paste it here and press Use access token.
